# WiFi Bilimsel Radar v5 — Play Store Edition

Yerel RF/CSI ölçüm laboratuvarı. İki mod: ESP32 CSI füzyon ve sensörsüz Android Wi‑Fi laboratuvarı.

- compileSdk 36
- targetSdk 36
- minSdk 26
- Java 17
- Reklam/analitik SDK yok
- Android App Bundle üretimine hazır
