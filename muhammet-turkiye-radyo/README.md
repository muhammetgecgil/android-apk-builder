# Muhammet Türkiye Radyo

Bu dal, mevcut Türk Radyo çalışmasından bağımsız ve paralel geliştirilecek yeni proje alanıdır.

## Ana kural
- Mevcut radyo uygulamasının görsel tasarımı, tema sistemi, ekran düzeni, ikonları veya UI bileşenleri kopyalanmayacak.
- Yeni arayüz sıfırdan tasarlanacak.
- Kod mimarisi de yeni proje olarak ele alınacak; yalnız genel Android/CI altyapısı paylaşılabilir.
- Bu proje için alınan kararlar `PROJECT_CONTEXT.md` dosyasında tutulacak.
