# Kaynak geri kazanım notu

Sesli Rehber v2.2'nin özgün proje klasörü çalışma alanında bulunmadığı için Java ve Android kaynakları kullanıcıya ait imzalı `SesliRehber-Muhammet-Niyet-v2.2.apk` dosyasından JADX 1.5.6 ile geri kazanıldı.

Geri kazanılan kaynak:

- `MainActivity.java`
- `IntentEngine.java`
- `ScreenReaderService.java`
- Android manifesti ve kaynak XML dosyaları

D8 tarafından oluşturulan sentetik lambda sınıfları korunmuştur; bu nedenle kaynak okunabilir fakat elle yazılmış temiz bir proje kadar sade değildir. GitHub CI derlemesi bu kaynakların yeniden üretilebilirliğini denetler. Özgün imzalama özel anahtarı APK içinde bulunmaz ve depoya eklenmemiştir.
