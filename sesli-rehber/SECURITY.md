# Güvenlik

Bu depo kontrollü pilot yazılım içerir. Kamera hareket takibi; araç, çukur, kaldırım, duvar veya geçiş güvenliği sertifikası değildir. Güvenlik açığını ya da tehlikeli yanlış davranışı herkese açık bir sorun kaydıyla paylaşmadan önce geliştiriciye özel kanaldan bildirin.

Depoda Play Store yükleme anahtarı, API anahtarı, parola veya kullanıcı verisi tutulmamalıdır. `release-unsigned.aab` dosyası yalnızca gizli yükleme anahtarıyla güvenli ortamda imzalanmalıdır.
